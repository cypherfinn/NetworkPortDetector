================================================================================
  GIT BENUTZERNAME ÄNDERN
================================================================================

PROBLEM:
--------
Der Commit zeigt "Spethmann" statt "cypherfinn"

LÖSUNG:
-------
Git-Konfiguration ändern und neu committen

BEFEHLE (In PowerShell ausführen):
-----------------------------------

1. Git-Benutzername global ändern:

   git config --global user.name "cypherfinn"
   git config --global user.email "your-email@example.com"


2. Aktuellen Commit mit neuem Namen erstellen:

   cd C:\Users\f.spethmann\NetworkPortDetector-GitHub

   # Neuen Branch erstellen (ohne alte History)
   git checkout --orphan new-main

   # Alle Dateien hinzufügen
   git add .

   # Commit mit korrektem Namen
   git commit -m "Initial commit: Network Port Detector v1.0.0 (English + German)"

   # Alten main löschen
   git branch -D main

   # Umbenennen
   git branch -m main

   # Push
   git push -f origin main


3. Konfiguration prüfen:

   git config user.name
   git config user.email


WICHTIG:
--------
- Ersetzen Sie "your-email@example.com" mit Ihrer GitHub E-Mail
- Oder verwenden Sie die GitHub no-reply E-Mail:
  username@users.noreply.github.com

GITHUB NO-REPLY E-MAIL:
-----------------------
Für Privatsphäre verwenden Sie:

   git config --global user.email "cypherfinn@users.noreply.github.com"

Diese E-Mail ist öffentlich sichtbar in Commits, zeigt aber nicht Ihre echte E-Mail.

DANACH:
-------
Alle zukünftigen Commits verwenden "cypherfinn" als Autor.
