  GIT HISTORY BEREINIGEN - .exe komplett entfernen
================================================================================

PROBLEM:
--------
Die .exe ist noch in der Git-History, auch wenn sie gelöscht wurde.
GitHub lehnt den Push ab, weil die .exe in einem alten Commit vorhanden ist.

LÖSUNG:
-------
Komplette Git-History zurücksetzen und neu starten.

BEFEHLE (In PowerShell ausführen):
-----------------------------------

1. In das Repository-Verzeichnis wechseln:

   cd C:\Users\f.spethmann\NetworkPortDetector-GitHub


2. Aktuellen Branch löschen:

   git checkout --orphan new-main


3. Alle Dateien zum neuen Branch hinzufügen:

   git add .


4. Ersten Commit erstellen (ohne alte History):

   git commit -m "Initial commit: Network Port Detector v1.0.0"


5. Alten main Branch löschen:

   git branch -D main


6. Neuen Branch zu main umbenennen:

   git branch -m main


7. Force Push zum Server:

   git push -f origin main


FERTIG!
-------
Die .exe ist nun komplett aus der Git-History entfernt.
Der Push sollte jetzt funktionieren.

DANACH:
-------
GitHub Release erstellen und .exe hochladen!
