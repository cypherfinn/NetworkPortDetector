--------
Die NetworkPortDetector.exe (171 MB) ist zu groß für GitHub (max. 100 MB).

LÖSUNG:
-------
.exe aus Repository entfernen und nur als Release hochladen.

BEFEHLE (In PowerShell ausführen):
-----------------------------------

1. In das Repository-Verzeichnis wechseln:

   cd C:\Users\f.spethmann\NetworkPortDetector-GitHub


2. Die .exe aus dem Git-Cache entfernen:

   git rm --cached NetworkPortDetector.exe


3. Status prüfen (sollte zeigen: deleted: NetworkPortDetector.exe):

   git status


4. Alle Änderungen zum Commit hinzufügen:

   git add .


5. Commit erstellen:

   git commit -m "Remove .exe from repository (will be added as GitHub Release)"


6. Force Push (um die History zu überschreiben):

   git push -f origin main


NACH ERFOLGREICHEM PUSH:
-------------------------

7. GitHub Release erstellen:

   a) Gehen Sie zu: https://github.com/cypherfinn/NetworkPortDetector/releases

   b) Klicken Sie "Create a new release"

   c) Tag version: v1.0.0

   d) Release title: Network Port Detector v1.0.0

   e) Beschreibung: (Kopieren Sie aus docs/RELEASE.md)

   f) Attach binaries: Laden Sie die .exe hoch
      Datei liegt hier: C:\Users\f.spethmann\NetworkPortDetector.exe.backup

   g) Klicken Sie "Publish release"


8. Fertig! Die .exe ist nun als Download verfügbar unter:

   https://github.com/cypherfinn/NetworkPortDetector/releases/latest


WICHTIG:
