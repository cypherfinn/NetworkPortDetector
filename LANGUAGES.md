## 🌍 Contributing Translations

Want to add a new language? We welcome translations!

1. Copy `README_EN.md` to `README_[LANG].md` (e.g., `README_FR.md` for French)
2. Translate the content
3. Add your language to this file
4. Create a Pull Request

**Most helpful translations:**
- French (Français)
- Spanish (Español)
- Polish (Polski)
- Dutch (Nederlands)
- Italian (Italiano)

See [CONTRIBUTING.md](docs/CONTRIBUTING.md) for details.
